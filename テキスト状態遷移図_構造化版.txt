【第1階層：試合の大枠状態（GameState）】
試合前
┌---------------------------┐
│  preGame                  │
└---------------------------┘
        │  チーム名入力 → preQuarter
        ▼

各Q前設定
┌---------------------------┐
│  preQuarter               │
└---------------------------┘
        │  出場5名選択 → 開始 → inGame
        ▼

試合中
┌---------------------------┐
│  inGame                   │
└---------------------------┘
        │
        ├───────────────────────────────────────────────┐
        │                                               │
        ▼                                               ▼

【第2階層：操作モード（OperationMode）】
ファール操作
┌---------------------------┐
│  foulMode                 │
└---------------------------┘
        │  赤/青選択 → ゼッケン選択 → confirmFoul
        ▼

交代操作
┌---------------------------┐
│  substitutionMode         │
└---------------------------┘
        │  出場 → 控え選択 → confirmSubstitution
        ▼

次のQへ
┌---------------------------┐
│  quarterControl           │
└---------------------------┘
        │  halfTime へ
        ▼

【第3階層：確認状態（ConfirmState）】
ファール確認
┌---------------------------┐
│  confirmFoul              │
└---------------------------┘
        │  OK → inGame
        │  修正 → foulMode
        ▼

交代確認
┌---------------------------┐
│  confirmSubstitution      │
└---------------------------┘
        │  OK → inGame
        ▼

【第1階層へ戻る】
ハーフタイム
┌---------------------------┐
│  halfTime                 │
└---------------------------┘
        │  チームファール自動クリア
        │  Q1〜Q3 → preQuarter
        │  Q4 → postGame
        ▼

試合後
┌---------------------------┐
│  postGame                 │
└---------------------------┘
        │  試合終了 → preGame
        │  延長戦 → OT → preQuarter
        ▼
      （終了）
