Basketball Foul Counter – 人語仕様書（レイヤ6まで）
============================================================

この仕様書は、Basketball Foul Counter アプリの
「レイヤ1〜6までの人間向け説明書」です。

技術的な JSON やモデル構造ではなく、
アプリの動作・画面・操作・デザインを
“人間が読んで理解できる形” でまとめています。

============================================================
【レイヤ1：ゲーム仕様（何を扱うアプリか）】
------------------------------------------------------------
・ミニバスの試合で使う「ファール管理アプリ」
・審判のコールに合わせて、補助員がスマホで操作する
・個人ファール、チームファール、退場、交代、クォーター進行を扱う
・試合は Q1〜Q4＋必要なら延長（OT）
・各クォーター開始時に出場選手5名を選ぶ
・個人ファールは最大5で退場
・チームファールは各クォーターでリセット

============================================================
【レイヤ2：モデル仕様（アプリが持つ情報）】
------------------------------------------------------------
・選手（ゼッケン番号、個人ファール、退場状態）
・チーム（名前、色、選手一覧、チームファール）
・試合（現在のクォーター、試合状態、両チームの情報）

============================================================
【レイヤ3：ViewModel仕様（アプリの内部動作）】
------------------------------------------------------------
・今どの画面か（試合前、試合中、ハーフタイムなど）
・今どの操作モードか（ファール、交代、クォーター進行）
・選択中のチーム、選手
・ファール確認画面の内容
・クォーター進行の制御
・編集モードの制御

============================================================
【レイヤ4：UI構造（画面の種類）】
------------------------------------------------------------
1. チーム選択画面（赤／青）
2. ゼッケン選択画面（出場選手のみ）
3. ファール確認画面（OK／修正）
4. 交代モード画面
5. クォーター前設定画面（出場選手5名選択）
6. ハーフタイム画面（状態遷移のみ）
7. 試合後画面（終了／延長）
8. 編集モード画面（halfTime／postGameのみ）

・スマホの縦向きが基本
・横向きは補助（画面が広くなる）

============================================================
【レイヤ5：操作仕様（誤操作ゼロ設計）】
------------------------------------------------------------
■ファール操作（審判コール同期）
  1. 赤／青をタップ
  2. ゼッケンをタップ
  3. 確認画面で OK または 修正
     → 自動で進まない（誤操作防止）
     → 表示する数字は「加算後のファール数」だけ

■誤操作修正
  - 赤青の押し間違い → 色切替ボタンで即修正
  - ゼッケン押し間違い → 確認画面の「修正」
  - 編集モードは試合中は使わせない

■交代モード
  - 出場 → 控えの順にタップ
  - 「交代しますか？」で確定

■クォーター進行
  - 試合中 → ハーフタイム
  - ハーフタイムで内部判定
    - Q4 → 試合後
    - Q1〜Q3 → 次のクォーター前設定

■編集モード
  - 個人ファール ±1
  - 退場解除（管理者のみ）
  - チームファール修正（管理者のみ）

■ゼッケン並び順（推奨→採用）
  - 昇順固定（誤操作防止）

============================================================
【レイヤ6：UIデザイン仕様（ポップ＆キッズ向け）】
------------------------------------------------------------
■デザイン思想
  - かわいい、親しみやすい、柔らかい
  - 子供でも直感的に使える
  - アイコンの世界観を統一
  - 誤操作ゼロのためにシンプル構造
  - 縦向きが基本、横向きは補助

■色（ポップ系）
  - 赤：#FF6B6B
  - 青：#4D9FFF
  - 黄：#FFD93D
  - 緑：#6BCB77
  - 紫：#A66CFF
  - 背景：#FAFAFA / #F0F0F0
  - 退場：#FF3B3B

■フォント
  - Rounded M+
  - Nunito / Quicksand

■アイコン
  - 丸みのあるポップ系
  - 線太め
  - 統一された世界観

■縦向き（portrait）
  - 赤／青は上下
  - ゼッケンは縦に並べる
  - 交代モードは上下構造

■横向き（landscape）
  - 赤／青は左右
  - ゼッケンは横に広く並べる
  - 編集モードは横で広く表示

■ファール確認画面
  - ポップなカード型
  - 加算後ファール数だけ表示
  - OK（緑）／修正（紫）

■音フィードバック（推奨→採用）
  - ファール確定：ポン
  - 修正：ピッ
  - 交代確定：キュッ
  - 退場：短いブザー
  - クォーター進行：チャイム
  - ミュート設定あり
